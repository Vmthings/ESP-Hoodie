UI font (optional). Put two VLW font files here:
  regular.vlw   bold.vlw
Generate them at 40 px, ASCII 32-126 only (Processing "Create Font" tool, or any TTF->VLW converter).
Upload with: pio run -t uploadfs
Without them the OS uses the built-in FreeSans fonts.

SF Pro: Apple's licence limits SF to apps for Apple platforms and it cannot be redistributed, so it is not bundled.
If you are allowed to use your own copy, convert it yourself and drop it in here. Inter (SIL OFL) is a very close, freely usable alternative.
